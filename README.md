Музыкальный бот (как @loaditbot)
Как работает
Поиск — SoundCloud через его API. Бот ищет прямо там, откуда потом качает, поэтому каждый результат в выдаче скачивается целиком. Платные отрывки (SoundCloud Go+) и треки с DRM отфильтровываются ещё до показа. Результаты сортируются по совпадению с запросом, явно посторонние отбрасываются.
Ссылки: SoundCloud (треки, плейлисты, короткие on.soundcloud.com) и Deezer (бот находит этот трек на SoundCloud). Ссылки на YouTube не поддерживаются.
Отправка: сначала в чат уходит «⏳ Загружаю…», потом сообщение подменяется на трек. Работает и в личке, и через @бот название.
Кэш: каждый трек скачивается один раз и хранится в канале-хранилище, потом отправляется мгновенно.
Защита сервера: всё длиннее 10 минут и прямые эфиры не скачиваются.
Каталог + YouTube (по желанию)

USE_CATALOG=1 добавляет в конец выдачи треки из Deezer/iTunes, которых нет на SoundCloud. Аудио для них бот ищет на YouTube Music / SoundCloud по названию и длительности (AUDIO_SOURCES). Такие треки грузятся не всегда, а YouTube с российских IP часто требует cookies (YTDLP_COOKIES_BROWSER=firefox) или прокси (YTDLP_PROXY).

Настройка
В @BotFather:
/setinline — включить инлайн-режим, плейсхолдер «название/ссылка».
/setinlinefeedback → Enabled (100%). Без этого плашка «Загружаю…» не заменится на трек.
Создайте приватный канал и добавьте бота администратором с правом публикации сообщений. В STORAGE_CHAT_ID укажите ID вида -100….
Установите ffmpeg: ffmpeg -version должен работать в терминале. На Windows: winget install Gyan.FFmpeg, затем перезапустите терминал/PyCharm.
Запуск:
   pip install -U -r requirements.txt
   python bot.py

При запуске бот проверяет ffmpeg и доступ к каналу. Проверка в любой момент: /check.
